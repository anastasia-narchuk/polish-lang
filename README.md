# polish-lang

iOS-приложение для изучения польского и подготовки к госэкзамену.

| Раздел | Что умеет |
|---|---|
| **Чтение** (ТЗ 2) | Текст по теме на уровне A1–B2 и выбранного типа, «Проще/Сложнее/Другой текст». Читалка: тап по слову или фразе → перевод в контексте предложения, начальная форма, чередование, перевод предложения. «Добавить в карточки» сохраняет форму из текста и всё предложение как пример. История текстов. |
| **Карточки** (ТЗ 1) | Свои слова в той форме, как встретились: по одному, списком, с фото тетради (сканер или галерея, до 3 фото). AI переводит именно эту форму; экран проверки перед сохранением. Повторение: ответ вводится с клавиатуры, сравнение строгое с диакритикой, «почти» для ogonki и одной буквы, побуквенный дифф, банк ошибок по типам. |
| **Письмо** (ТЗ 3, этап 1) | Подготовка к письменной части экзамена B1–B2. Ступени Akapit (абзац 50–80 слов с пятью словами из карточек) и Egzamin (задания экзамена, лучше от руки), «Тренировка формы» (e-mail, list formalny, reklamacja…) и «Свой текст» из пробного теста. Рабочее место: лист в клетку, панель ą…ż в позицию курсора, счётчик слов, опора (план, связки, идеи RU→PL по тапу) по таблице видимости, фото рукописи со сверкой расшифровки, чек-лист. Разбор: балл /25 → %, баллы задания, покрытие пунктов ✓/≈/✗, регистр, ошибки красной ручкой, исправленная версия, «на уровень выше», слова в карточки. История, банк ошибок, «Мои ловушки». |
| **Настройки** | AI: Claude или Gemini, у каждого свой ключ и модель; письмо: уровень, лимиты слов, баллы, время, панель букв; автосохранение текстов, экспорт данных в JSON. |

## Дизайн

Формы и размеры взяты с сайта Wise: кнопки-пилюли 48/40/32 pt, карточки со скруглением 24–32 pt, иконки в кругах 48 pt, прогресс-бары 8 pt, тёмные карточки разделов с пастельными заголовками, шрифт Inter с плотными заголовками. Палитра своя: малиновый `#FF7E9D` с винным `#3D0A1A` вместо зелёного Wise, у каждого раздела своя тёмная карточка. Все токены и компоненты — в `ios/PolishLang/UI/Design` (`Theme.swift`, `Components.swift`). Inter (SIL Open Font License, `UI/Design/Fonts/Inter-OFL.txt`) встроен в приложение; длинный текст в читалке остаётся антиквой New York.

## Как запустить

1. Нужен Xcode 16 или новее, iPhone или симулятор с iOS 17+.
2. Открыть `ios/PolishLang.xcodeproj`.
3. Target **PolishLang** → Signing & Capabilities → выбрать свою команду (Team). Если Xcode скажет, что bundle id занят, поменять его на любой свой.
4. Запустить (⌘R).
5. В приложении: **Настройки** → выбрать Claude или Gemini → вставить ключ (Claude: console.anthropic.com → API Keys; Gemini: aistudio.google.com → API keys, бесплатный тариф — только в проекте без привязанного биллинга) → «Проверить подключение».

Без ключа приложение работает: карточки можно добавлять с ручным переводом, повторение и история текстов доступны.

## Тесты

```bash
cd ios && swift test
```

Тесты ядра запускаются на macOS и на Linux, симулятор не нужен. Они покрывают критерии приёмки, которые проверяются без живой модели: разбор списков, пайплайн карточек, повторы, исправление опечаток, проверка ответа и типы ошибок, разбиение текста на слова и предложения, проверки сгенерированного текста, лимиты запросов, формат запросов к API и обработку ошибок (с фейковым сервером).

GitHub Actions (`.github/workflows/ios.yml`) на каждый пуш в `ios/` прогоняет тесты, собирает приложение и снимает скриншоты основных экранов в симуляторе (светлая и тёмная тема) — они лежат в артефакте `screenshots` у запуска.

## Демо-режим (только Debug-сборка)

Аргументы запуска `-demo -demo-screen <экран>` (Xcode → Product → Scheme → Edit Scheme → Run → Arguments): тестовые карточки, текст и разбор письма во временной папке и «фейковый Claude», который отвечает заготовками — все экраны открываются без сети и без ключа. Экраны: `setup`, `reader`, `panel`, `cards`, `add`, `review`, `study`, `settings`, `writing`, `workspace`, `feedback`. Настоящие данные демо-режим не трогает.

## Структура

```
ios/
  PolishLang.xcodeproj   проект; папка PolishLang синхронизируется, новые файлы подхватываются сами
  Package.swift          пакет PolishCore для тестов: те же исходники Core, что и в приложении
  PolishLang/
    Core/                всё без SwiftUI и UIKit: модели, промпты, клиент Claude API, парсеры,
                         хранилища и модели экранов
    Platform/            Keychain, подготовка фото, сканер документов, поле ввода ответа
    UI/                  экраны SwiftUI
    Assets.xcassets
  PolishCoreTests/
```

Данные хранятся на устройстве в JSON-файлах (Application Support): карточки, история текстов, банк ошибок, фото, с которых распознаны слова.

## Работа с AI: Claude и Gemini

- Провайдер выбирается в настройках; промпты, JSON-схемы и разбор ответов общие.
- **Gemini:** `generateContent` (`v1beta`), ключ в заголовке `x-goog-api-key`, structured output через `responseJsonSchema`, effort → `thinkingLevel`. Модель по умолчанию `gemini-3.5-flash`; при перегрузке (503) запрос один раз повторяет `gemini-3.5-flash-lite` (выключается в настройках). 402 «prepayment credits are depleted» значит, что к проекту ключа привязан биллинг: бесплатный тариф работает только в проекте без него. Дневной лимит бесплатного тарифа сбрасывается в полночь по тихоокеанскому времени. Живые проверки: `GEMINI_API_KEY=… swift test --filter LiveAITests` (без ключа пропускаются).
- **Claude:** Messages API напрямую, версия API `2026-10-21`. Модель по умолчанию `claude-sonnet-5-5` (как в ТЗ), меняется в настройках.
- Ключи хранятся только в Keychain устройства, в коде и в репозитории их нет. В настройках можно указать свой прокси, совместимый с Messages API: пригодится, если приложением будут пользоваться другие люди и ключ должен остаться на сервере.
- Ответы — JSON по схеме (structured outputs) плюс терпимый разбор: целиком, из блока ```json или от первой скобки до последней. Автоматических повторов в цикле нет, при ошибке — сообщение и «Ещё раз».
- Пакетные ответы (4.1 и 4.2 из ТЗ 1) приходят как `{"items": [...]}`: схема требует объект в корне. Парсер принимает и голый массив.
- Включена бета-функция `fallbacks: "default"`: если модель откажется отвечать по правилам безопасности, запрос повторит резервная модель. Выключается в настройках; если бета недоступна аккаунту, запрос сам повторяется без неё.
- Лимиты на устройстве: 5 генераций и 30 переводов в минуту («Подожди минуту», кнопка оживает по таймеру). Ответ 429 от API обрабатывается так же.

## Как ТЗ перенесены на iOS

- `localStorage` → настройки в UserDefaults; история и карточки — в файлах.
- «Никакого innerHTML» → текст модели выводится только как обычные строки. Слова в читалке — ссылки `plword://<id>` внутри одного `Text`, поэтому текст переносится как обычный.
- Панель перевода справа на большом экране и снизу на телефоне → на iPad колонка справа внутри читалки, на iPhone лист на полэкрана; при открытом листе можно тапать следующие слова. (`inspector` не подошёл: внутри `NavigationStack` на iPhone он закрывал читалку сразу после открытия.)
- Выделение фразы на тач-экране → кнопка «Фраза»: тап по первому слову, тап по последнему, «Перевести фразу».
- Поле ответа в повторении: без автокоррекции, заглавных и проверки орфографии; польская раскладка включается сама, если она установлена (аналог `lang="pl"`), плюс панель ą ć ę ł ń ó ś ź ż.
- Удаление в два нажатия без `confirm()`: свайп и «Удалить» в истории, «Удалить карточку» → «Точно удалить?».
- Фото сохраняются, у карточки есть `photoId`: снимок можно открыть из карточки.
- В промпт перевода слова (4.2 ТЗ 2) добавлена просьба давать подсказку о форме в скобках — так получается «врача (род./вин. п.)» из критерия приёмки.
- `usedMyWords` модель возвращает в форме, как в тексте, чтобы их можно было подсветить. Слова из карточек подсвечиваются всегда — по форме и по начальной форме.
- Повторение по Лейтнеру: интервалы 0, 1, 2, 4, 8, 16, 32 дня. «Почти» и ответ после подсказки — шаг назад, ошибка — в начало и повтор в этой же сессии.

## Как ТЗ 3 перенесено на iOS

- Двухколоночное рабочее место (≥880px) → на iPad опора колонкой справа со своей прокруткой, на iPhone — карточка между заданием и полем (открыта на Akapit, свёрнута в тренировке Egzamin).
- `textarea` «лист в клетку» → `UITextView` на клетчатом фоне с красными полями, антиква New York ≥19 pt, без автокоррекции, польская раскладка; панель ą…ż с Shift — над клавиатурой, вставляет в позицию курсора.
- Mongo/коллекции → JSON-файлы: `writing.json` (тексты), `text-errors.json` (банк ошибок текстов), `writing-draft.json` (черновик); фото листа — в той же папке `photos/`.
- Лестница: только письменные ступени Akapit → Egzamin (Egzamin открывается после 3 абзацев ≥70%, из них 2 от руки, или досрочно); «Słowo» — повторение карточек.
