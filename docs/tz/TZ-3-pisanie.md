# ТЗ 3. Подготовка к письменной части экзамена (Pisanie, B1–B2)

> Документ для Claude в новой сессии. Реализуй модуль по этому описанию, этапами из раздела 13. Если что-то противоречит коду проекта или ТЗ 1 и 2, сначала спроси.
>
> Пометки у функций:
> - **[Codex]** — предложено в варианте ChatGPT Codex (экран «Polski · письменная практика»);
> - **[Есть]** — уже работает в артефакте «Pisz po polsku» (`Claude code/polish-coach/index.html`);
> - **[Новое]** — рекомендация в этом ТЗ, ещё нигде не реализована.

## 1. Цель и пользователь

- **Пользователь:** взрослая, родной язык русский. Готовится к государственному экзамену по польскому (Państwowy Egzamin Certyfikatowy) на B1, с запасом на B2. Занимается 15–20 минут в день, по выходным дольше.
- **Проблемы:**
  1. словарь пассивный: узнаёт слова в тексте, но не вспоминает их сама;
  2. орфография плывёт (ó/u, rz/ż, ch/h, ą/ę, nie слитно/раздельно);
  3. на экзамене текст пишется **от руки и без словаря**.
- **Цель модуля:** постепенно довести до уверенного написания экзаменационного текста от руки, из головы, в нужной форме, объёме и регистре, с баллом выше порога.

## 2. Формат экзамена (справка, значения настраиваемые)

Подтверждено в открытых источниках (certyfikatpolski.pl, регламенты центров):
- **B1:** на выбор 3 набора тем, в каждом по 2 задания. Задание 1 — короткая форма (поздравление, приветствие, приглашение, объявление, записка). Задание 2 — длинная форма (письмо, отчёт, рассказ). Требуемое число слов указано в каждом задании.
- **B2:** более длинные тексты, аргументация или сравнение, формальное письмо.
- Модуль «Pisanie» в экзаменационных листах оценивается в **30 баллов**. Порог по модулю: **50% для B1, 60% для B2**.
- Вся письменная часть (все модули) длится 190 мин на B1 и 250 мин на B2.

**Не подтверждено, вынести в настройки:**
- лимиты слов по заданиям. По умолчанию B1 ≈ 50 / 150, B2 ≈ 120 / 250;
- раздел 30 баллов между двумя заданиями. По умолчанию 10 / 20;
- время на сам модуль письма. По умолчанию 60 мин для B1, 75 мин для B2;
- официальные критерии оценки.

Скачать официальные образцы автоматически не удалось: сайт отвечает 403. Пользователь сверит значения с «Przykładowe testy» вручную. В интерфейсе рядом с этими настройками показывать подсказку «сверь с пробным тестом».

## 3. Принципы (обязательны для всех экранов)

1. **Сначала производство, потом подсказка.** Пользователь не видит польских готовых фраз и слов до попытки. Подсказки открываются ступенями, и каждая фиксируется в статистике.
2. **Опора исчезает с ростом уровня (fading scaffolding).** На ранних ступенях видны план, связки и идеи. В режиме экзамена ничего этого нет. Таблица в разделе 5.
3. **От руки — основной режим на старших ступенях.** Ввод с клавиатуры служит тренировкой, финальная проверка идёт по фото листа.
4. **Каждая ошибка возвращается.** Ошибки текста попадают в банк ошибок, из него строятся орфодрилы и персональные «ловушки» (раздел 7.5).
5. **Честная, экзаменоподобная оценка.** Баллы по критериям, порог, покрытие пунктов задания. Без инфляции похвалы.
6. **Сначала найди ошибки сам, потом смотри исправления.** Двухпроходная проверка (раздел 7.3).

### 4.1. Хаб «Pisanie»
- Верхний блок **«Готовность к экзамену»** [Новое]:
  - прогноз балла /30 по последним 3 экзаменационным текстам и линия порога;

- Карточки-запускатели. В каждой: название, одна строка «что делаешь», бейдж ступени или «досрочно» [Есть].

### 4.2. Рабочее место (главный экран)

Десктоп, ширина 880px и больше: две колонки. Опора справа, липкая, со своей прокруткой [Есть, Codex].

```
┌──────────────────────────────────────────────┬─────────────────────────┐
│ [B1 · opinia]                    ⏱ 12:40     │ Опора для текста [Спрятать]│
│ Czy warto uczyć się języków obcych…?         │ 1 · Вступление           │
│ • opinia • 2 argumenty • przykład            │   Moim zdaniem… / Uważam…│
│ ▸ Перевод задания                            │ 2 · Аргументы            │
│ Обязательно: rozwój · możliwość · …          │   Po pierwsze… Poza tym… │
│ Объём 100–120 слов           [Другая тема]   │ 3 · Вывод                │
├──────────────────────────────────────────────┤   Podsumowując…          │
│ [Печатаю] [От руки · фото]                   │ Связки: jednak · dlatego │
│ ┌ лист в клетку с красными полями ─────────┐ │ Идеи (RU → нажми → PL):  │
│ │ Pisz tutaj…                              │ │  личностный рост → …     │
│ └──────────────────────────────────────────┘ │  шансы в работе          │

│ ☐ все пункты ☐ объём ☐ регистр ☐ ogonki      │                          │

└──────────────────────────────────────────────┴─────────────────────────┘
```

На мобильном одна колонка в порядке: задание → опора (свёрнута до заголовка) → поле → кнопки. Опора открывается шторкой.

Элементы:
- **Блок задания** [Есть, Codex]: форма, polecenie по-польски, пункты списком, сворачиваемый «Перевод задания», обязательные слова и связки как чипы. Чип становится зелёным, когда слово использовано в любой форме (совпадение по основе). Целевой объём, кнопка **«Другая тема»** с подтверждением, если уже есть текст [Есть, Codex].
- **Поле ввода** [Есть]: «лист в клетку» с красными полями, антиква 18px. Атрибуты `autocorrect=off`, `spellcheck=false`, `autocapitalize=off`, `lang="pl"`. Автосохранение черновика каждые 2 с паузы.
- **Панель польских букв** под полем [Новое]: `ą ć ę ł ń ó ś ź ż` и Shift для заглавных. Вставка в позицию курсора. Нужна тем, у кого нет польской раскладки. Скрывается в настройках.
- **Живой счётчик слов** [Есть, Codex]: «87 слов · цель 100–120». Зелёный в диапазоне, жёлтый при отклонении до 20%, красный за пределами.
- **Таймер** [Есть для экзамена]: секундомер, в режиме экзамена обратный отсчёт. На 10 минутах до конца ненавязчивое предупреждение, без звука.
- **Чек-лист самопроверки перед отправкой** [Новое]: все пункты задания, объём, регистр (Pan/Pani или ty, единообразно), формулы начала и конца для писем, ogonki проверены. Это ручные галочки, они не блокируют отправку, но сохраняются в статистику.
- **Режим «От руки · фото»** [Есть]:
  - подсказка «пиши без телефона и словаря»;
  - загрузка 1–3 фото;
  - превью с поворотом на 90° [Новое];
  - после загрузки расшифровка, которую пользователь сверяет: исправляет только неверно прочитанное, свои ошибки не трогает [Есть].
- **Кнопки:** «Самопроверка» (раздел 7.3, проход 1) и «Разобрать с коучем» (полная проверка) [Codex, название кнопки взять оттуда].

### 4.3. Опора для текста [Codex, Есть, расширить]
- **План** из 3–4 частей. Нумерация отражает реальный порядок частей. У каждой части 2–3 польских начала фраз под эту форму. Для писем: формулы обращения и прощания (Szanowni Państwo, / Z poważaniem, / Pozdrawiam serdecznie).
- **Связки:** 4–6 под форму.
- **Идеи:** **сначала русская мысль, польский вариант по нажатию** [Новое относительно Codex]. У Codex польские слова видны сразу, это нарушает принцип 1. Каждое раскрытие считается.
- **«Мои ловушки»** [Новое]: 2–3 самые частые ошибки пользователя из банка, например «rz/ż: morze, może», «Pan/Pani или ty — не смешивай».
- Кнопка **«Спрятать / Показать»** [Codex]. Видимость по умолчанию зависит от ступени (раздел 5).

### 4.4. Экран разбора (feedback)

Порядок блоков сверху вниз:
1. **Итог** [Есть]:
   - большой балл в процентах и в баллах задания (например 14/20);
   - порог B1/B2;
   - 5 полос критериев 0–5;
   - 2–3 предложения резюме по-русски;
   - строка «слов: 112 · от руки · с опорой, подсмотрено идей 2/6 · 34 мин».
2. **Покрытие пунктов задания** [Новое]: каждый пункт с отметкой ✓, ≈ или ✗ и цитатой из текста, где он раскрыт. Это главный источник потери баллов за выполнение задания.
3. **Регистр и форма** [Новое]: формальный или неформальный, единообразие, формулы начала и конца; что не так.
4. **Текст с ошибками** [Есть]: волнистое подчёркивание с номером. По тапу подсвечивается пункт списка: фрагмент → исправление, тип ошибки, правило по-русски.
5. **Исправленная версия** [Есть]: свёрнута. Минимальная правка, стиль пользователя сохранён.
6. **«Как сказать на уровень выше»** [Есть]: 3 пары «было → лучше» с пояснением.
7. **Слова и фразы для повторения** [Есть, Codex]: чекбоксы и кнопка «Добавить в карточки». Карточки создаются по пайплайну ТЗ 1, с сохранением формы.
8. **Пример на высокий балл** [Новое]: открывается только после проверки. Образцовый текст на этот же polecenie и уровень, полезные фразы подсвечены, их можно добавить в «Мои фразы».
9. **Кнопка «Переписать»** [Новое]: открывает рабочее место с исходным текстом, исправленная версия и пример скрыты. После повторной проверки показывается дельта: «было 58% → стало 76%, исправлено 7 из 9 ошибок».

### 4.5. Симуляция экзамена [Новое]
- Пользователь выбирает 1 из 3 сгенерированных наборов. В наборе 2 задания: короткая и длинная форма для B1, для B2 формы по профилю B2.
- **Общий таймер** на модуль. Опора, перевод задания и подсказки отключены. Поле ввода отключено, режим только «От руки · фото».
- Оба задания сдаются вместе: фото, затем сверка расшифровки, затем проверка.
- **Итог:** балл /30 (раздел 30 баллов по настройке), статус «сдано / не сдано» относительно порога, разбор по каждому заданию (как 4.4), затраченное время.

### 4.6. Wzory: шаблоны форм [Новое]
- Справочник по каждой форме:
  - назначение;
  - обязательные элементы (чек-лист);
  - каркас текста;
  - 6–10 формул: обращение, вступление, переходы, просьба, жалоба, прощание.
  Все формулы с переводом.
- **Формульный дрил:** по-русски «Уважаемые господа (официально)», пользователь пишет по-польски. Используются тот же компонент recall-карточки и строгая проверка орфографии, что в повторении слов. Формулы хранятся в отдельной колоде `phrases`.

### 4.7. Мои тексты и динамика [Есть, расширить]
- Список текстов: балл, форма, дата, бейджи «от руки» и «с опорой».
- **Графики** [Новое]:
  - балл во времени с линией порога;
  - 5 критериев во времени (small multiples);
  - ошибки на 100 слов по типам.
- Повторное открытие показывает разбор и фото листа [Есть].

## 5. Ступени и «исчезновение» опоры

Лестница сохраняется [Есть]: Słowo → Fraza → Zdanie → Akapit → Egzamin. Разблокировка идёт по метрикам, ступень можно открыть досрочно. Видимость элементов на письменных ступенях:

| Элемент | Akapit (печатаю) | Akapit (от руки) | Egzamin: тренировка | Egzamin: симуляция |
|---|---|---|---|---|
| План с началами фраз | открыт | открыт | скрыт, можно открыть | недоступен |
| Связки | открыты | открыты | скрыты, можно открыть | недоступны |
| Идеи (RU → PL по тапу) | открыты | открыты | скрыты, можно открыть | недоступны |
| Мои ловушки | открыты | открыты | открыты | недоступны |
| Перевод задания | можно открыть | можно открыть | можно открыть | недоступен |
| Панель польских букв | есть | — | — | — |
| Таймер | нет | нет | секундомер | обратный отсчёт |

Если на ступени Egzamin опору всё же открыли, в итог добавляется пометка «с опорой». Такой текст не идёт в прогноз готовности.

## 6. Рабочий процесс одного задания

1. **Zadanie:** прочитать задание и при желании открыть перевод.
2. **Pomysły** [Новое, необязательно]: 1–2 минуты накидать идеи по-русски в маленьком поле. Не проверяется, сохраняется вместе с текстом.
3. **Plan:** опора или свой план.
4. **Pisanie:** печатать или писать от руки.
5. **Autokorekta** [Новое]: чек-лист, затем «Самопроверка». Проход 1: только где ошибки, без исправлений. Пользователь правит сам.
6. **Sprawdzenie:** «Разобрать с коучем», полный разбор.
7. **Poprawa** [Новое]: «Переписать» и дельта.

Шаги 2, 5 и 7 можно пропустить. Шаги 1, 4 и 6 обязательны.

## 7. Контракты с AI

Модель: актуальная Claude (`claude-sonnet-5-5` через API или capability `sample` в артефакте). Промпты пишем по-польски, а пояснения для пользователя модель отдаёт по-русски. Ответ строго JSON, парсинг терпимый. Ошибка показывается с кнопкой «Ещё раз», автоматического ретрая в цикле нет.

### 7.1. Генерация задания (одно задание или набор для симуляции)
Вход: уровень, форма или «любая», тема или «любая», целевое число слов, для ступени Akapit 5 обязательных слов пользователя.

```
Jesteś autorem zadań Państwowego Egzaminu Certyfikatowego z języka polskiego jako obcego, poziom {B1|B2}.
Ułóż {jedno zadanie | 3 zestawy po 2 zadania: krótka forma + dłuższa forma} z części „Pisanie”.
Forma: {forma albo „dowolna odpowiednia do poziomu”}. Temat: {temat albo „z życia codziennego w Polsce”}. Liczba słów: około {N}.
{Akapit: W zadaniu musi dać się naturalnie użyć słów: …}
Dla każdego zadania:
- "form", "register": "formalny"|"nieformalny", "polecenie" (w stylu egzaminu), "punkty" (3–4 elementy treści do uwzględnienia), "words", "ru" (краткий перевод),
- "plan": 3–4 części [{"ru": nazwa części po rosyjsku, "phrases": 2–3 polskie początki zdań typowe dla tej formy}],
- "connectors": 4–6 wyrażeń łączących pasujących do formy,
- "ideas": 5–6 [{"ru": myśl po rosyjsku 2–5 słów, "pl": kluczowa polska kolokacja}].
Odpowiedz tylko JSON: {"sets":[{"tasks":[{...},{...}]}]} albo {"task":{...}}
```

### 7.2. Расшифровка рукописи [Есть]
Модель переписывает текст дословно, со всеми ошибками, ogonki как есть, абзацы сохраняются. Нечитаемое слово помечается `[?]`. Ответ — только текст. Расшифровку пользователь подтверждает до проверки.

### 7.3. Самопроверка, проход 1 [Новое]

```
Jesteś egzaminatorem. Nie poprawiaj tekstu. Dla każdego zdania tekstu uczennicy podaj tylko liczbę błędów i ich typy.
Tekst: """{text}"""
Odpowiedz tylko JSON: [{"sentence": dokładny tekst zdania, "errors": liczba, "types": ["ortografia"|"gramatyka"|"leksyka"|"składnia"|"interpunkcja"]}]
```

В интерфейсе в предложениях с ошибками появляется бейдж «2 · орф., грам.». Пользователь правит прямо в поле, затем запускает полный разбор. Число ошибок, найденных самостоятельно, сохраняется: это сравнение счётчиков до и после.

### 7.4. Полный разбор [Есть, расширить]

```
Jesteś egzaminatorem Państwowego Egzaminu Certyfikatowego, poziom {level}. Oceń tekst rosyjskojęzycznej uczennicy.
ZADANIE: {form}. {polecenie} Punkty: {punkty}. Rejestr: {register}. Długość: około {N} słów (tekst ma {n}).
{Obowiązkowe słowa: …}
TEKST: """{text}"""
Zwróć JSON:
- "errors": [{"fragment": DOKŁADNY fragment z tekstu, najkrótszy z błędem, "correction", "type", "rule_ru": max 20 słów po rosyjsku}] — nie oznaczaj poprawnych wariantów stylistycznych,
- "points": [{"punkt": tekst punktu, "status": "tak"|"częściowo"|"nie", "quote": cytat z tekstu albo ""}],
- "register": {"expected","detected","consistent": bool,"issues_ru": ["…"]},
- "scores": {"zadanie","spojnosc","gramatyka","leksyka","ortografia"} każde 0–5,
- "corrected_text": minimalna poprawa, styl uczennicy,
- "upgrade": 3 × {"plain","better","ru"},
- "new_words": 3–6 × {"pl" (forma jak należy użyć w tym kontekście),"base","ru"},
- "used": użyte obowiązkowe słowa,
- "summary_ru": 2–3 zdania po rosyjsku: co dobrze, co najważniejsze do poprawy.
```

Балл в процентах считается как сумма баллов / 25 × 100. Балл задания равен проценту от веса задания (10 или 20 по настройке). Это **приближение к официальной шкале**, в интерфейсе подписывается «оценка по нашей шкале».

### 7.5. Образцовый текст [Новое]
Вход: то же задание и уровень. Выход: `{"text", "phrases": [{"pl","ru","why_ru"}]}`. Длина в пределах целевой ±10%. Используются только конструкции, доступные на этом уровне.

### 7.6. Формулы для Wzory [Новое]
Набор формул по формам **генерируется один раз и сохраняется как статичные данные** в коде или базе, а не при каждом открытии. Перед первым релизом формулы проверяет человек.

## 8. Банк ошибок и «ловушки» [Есть, расширить]
- Каждая ошибка из 7.4 записывается так: id = hash(fragment → correction), поля `count`, `lastSeen`, `type` и подкатегория орфографии (ó/u, rz/ż, ch/h, ą/ę, nie, ogonki).
- Новая категория **«регистр»** из `register.issues_ru` [Новое].
- **Ловушки** — это топ-3 по формуле `count × (1 / дни с lastSeen)`. Показываются в опоре и перед началом симуляции.
- Ошибки орфографии уходят в ежедневный орфодрил [Есть]. Грамматические ошибки превращаются в микро-задания «вставь форму» на ступени Fraza [Новое].

## 9. Прогресс и готовность [Новое]
- **Прогноз /30:** среднее последних 3 текстов ступени Egzamin, написанных без опоры и от руки. Если таких меньше 3, показываем «мало данных».
- **Матрица форм:** строки — формы, колонки — «сделано раз», «средний балл», «последний раз». Пустые и слабые ячейки подсвечены. Кнопка «Потренировать эту форму».
- **Ошибки на 100 слов** по типам, тренд за 4 недели.
- **Самостоятельно найденные ошибки:** процент из прохода 1. Показатель растущей автономии.

## 11. UI/UX: требования и рекомендации [Новое, если не указано иное]

- **Визуальная метафора:** школьная тетрадь в клетку с красными полями [Есть]. Ошибки подчёркнуты «красной ручкой учителя», исправления зелёные. Цвета ошибок не путать с акцентом интерфейса.
- **Типографика:** антиква с полной диакритикой для польского текста (Literata или аналог). Интерфейс на гротеске с кириллицей. Минимум 18px в поле письма.
- **Фокус-режим:** кнопка «На весь экран». Скрывает шапку и вкладки, оставляет задание свёрнутым до одной строки, поле и счётчик.
- **Мобильный сценарий от руки:** шаг 1 «Пиши на бумаге» с таймером на весь экран и блокировкой сна, если её дадут. Шаг 2 «Сфотографируй»: подсказки по свету и одному листу в кадре.
- **Пустые состояния** объясняют следующее действие. Пример: «Пока нет текстов — начни с задания „Akapit“».
- **Задержки AI:** разбор занимает до минуты. Показываем этапы («Читаю рукопись… → Проверяю как экзаменатор…»), кнопку «Стоп» и не блокируем навигацию.
- **Без модальных `alert/confirm`.** Подтверждения встроены в кнопку («Текст удалится. Точно?») [Есть].
- **Тёмная тема** из токенов, контраст подчёркиваний проверен в обеих темах [Есть].
- **Доступность:** фокус-кольца, подчёркнутые ошибки доступны с клавиатуры (Tab, Enter), у ошибок есть `aria-label`.
- **Язык интерфейса:** русский. Учебный контент (задания, формулы, план) по-польски. Пояснения правил по-русски.

## 12. Ошибки и крайние случаи

| Ситуация | Поведение |
|---|---|
| Текст короче 5 слов | Кнопки проверки неактивны, подсказка |
| Текст намного длиннее цели | Проверяем, в разборе штраф по «zadanie» с пояснением |
| Фото не читается | Расшифровка с `[?]`. Если `[?]` больше 15% слов: «Сфотографируй ближе при дневном свете» |
| Перепутан порядок страниц на фото | Пользователь может перетащить превью перед расшифровкой |
| Модель вернула `fragment`, которого нет в тексте | Ошибка показывается в списке без подчёркивания |
| Обрыв во время разбора | Черновик и расшифровка сохранены, кнопка «Ещё раз» |
| Таймер симуляции истёк | Поле фото остаётся доступным 5 минут с пометкой «сдано после времени» |
| AI недоступен | Писать и сохранять черновики можно. Проверка недоступна, понятное сообщение |

## 14. Критерии приёмки

1. На ступени Akapit (печатаю) опора открыта, идеи показывают только русский текст. Тап открывает польский вариант, счётчик раскрытий растёт.
2. На ступени Egzamin в тренировке опора скрыта. После открытия текст в истории помечен «с опорой» и не участвует в прогнозе.
3. В симуляции нет поля ввода, перевода задания и опоры. Таймер идёт обратным отсчётом, итог выводится в /30 со статусом относительно порога.
4. В разборе письма с пропущенным пунктом этот пункт помечен ✗, балл «zadanie» не выше 3/5.
5. Письмо с «Szanowny Panie» и «jak się masz?» в одном тексте получает `register.consistent = false` и понятное замечание по-русски.
6. Самопроверка показывает только количество ошибок по предложениям, исправлений не видно.
7. «Переписать» скрывает исправленную версию. После проверки показывается дельта баллов и число исправленных ошибок.
8. Кнопка «ł» на панели букв вставляет символ в позицию курсора, фокус остаётся в поле.
9. Слова из «Слова для повторения» сохраняются в карточки в форме из текста (ТЗ 1).
10. Лимиты слов, вес заданий и время меняются в настройках и сразу применяются к новым заданиям.
