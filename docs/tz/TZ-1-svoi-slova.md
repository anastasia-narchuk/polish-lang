# ТЗ 1. Добавление своих слов во флеш-карточки (текстом и по фото)

> Документ для Claude в новой сессии. Реализуй функцию целиком по этому описанию. Если что-то противоречит коду проекта, сначала спроси.

## 1. Зачем это нужно

Пользователь учит польский (B1–B2, родной язык русский) и записывает слова **в той форме, в какой их встретил**: в падеже, лице, времени. Например, `rzece`, а не `rzeka`. Задача карточки: запомнить именно эту форму, то есть окончание и чередование согласных (r → rz, k → c, g → dz, ó → o и т.п.).

Поэтому:
- **Форма, которую ввёл человек, сохраняется без изменений.** Не приводить к словарной форме, не «исправлять» молча.
- **Перевод подбирает AI**, и перевод должен передавать **именно эту форму**, чтобы по нему можно было вспомнить форму.
- Человек **может указать начальную форму сам**. Если не указал, её определяет AI.
- Добавлять можно **текстом** (одно слово или список) и **по фото** (тетрадь, учебник, конспект урока). Слова с фото распознаются и попадают в тот же экран проверки.

Важное отличие от старого проекта polish-learner: там при добавлении сохранялась `baseForm` вместо исходной формы, а импорт «исправлял опечатки» автоматически. **В новой реализации оба поведения запрещены.**

## 2. Сценарии

### 2.1. Одно слово
Поля: **«По-польски»** (обязательное), **«Начальная форма»** (необязательное), **«Перевод»** (необязательное).
1. Пользователь вводит `rzece` и нажимает «Добавить».
2. Если перевод пустой, вызывается AI (раздел 4.1).
3. Открывается экран проверки (раздел 3), там можно поправить перевод, начальную форму и пометку. Затем нажать «Сохранить».
4. Если перевод введён вручную, а начальная форма не нужна, карточка сохраняется сразу, без AI и без экрана проверки.

### 2.2. Список текстом
Поле textarea. Поддерживаемые форматы строк:

| Строка | Что значит |
|---|---|
| `rzece` | только форма |
| `rzece — реке` | форма и перевод (разделитель: тире `—`/`–`/`-` с пробелами вокруг или Tab) |
| `rzece [rzeka]` | форма и начальная форма в квадратных скобках |
| `rzece [rzeka] — реке` | всё вместе |
| `morzu, przy rzece, poszłam` | одна строка без тире: список через запятую |

Правила разбора:
- Пустые строки игнорируются, пробелы по краям обрезаются.
- Если **во всём вводе одна строка**, в ней есть запятые и нет разделителя-тире, делим её по запятым. В остальных случаях запятая считается частью фразы.
- Многословные фразы допустимы (`zwrócić uwagę na`, `przy rzece`).
- Строки, для которых нужен AI (нет перевода или начальной формы), отправляются **одним батч-запросом**. Если строк больше 40, разбиваем на пачки по 40.

### 2.3. По фото
Кнопка **«Добавить с фото»** принимает до N изображений за раз (N берём из лимита модели или API, по умолчанию 3). Подходит фото страницы тетради, учебника или доски.
1. Переключатель режима:
   - **«Только выделенное»** (по умолчанию): подчёркнутое, обведённое, выделенное маркером, вынесенное на поля;
   - **«Все польские слова»**.
2. AI распознаёт польские слова и фразы **дословно, как они написаны на фото**, включая форму и ошибки (раздел 4.2). Русские слова рядом с польскими считаются переводом этого слова.
3. Распознанные элементы, у которых нет перевода или начальной формы, проходят через тот же батч-запрос 4.1. Можно объединить оба шага в один вызов, если модель стабильно отдаёт нужный JSON.
4. Результат попадает на экран проверки с пометкой источника «фото». Сомнительные прочтения подсвечены, исходное фото показано рядом для сверки.
5. Фото сохраняется, если в стеке есть хранилище файлов. Тогда у карточки ссылка `photoId`. Если хранилища нет, фото не храним.

## 3. Экран проверки перед сохранением

Список строк. В каждой строке:
- **Форма (pl)**, только для чтения, крупно, шрифт с хорошей диакритикой.
- **Подсказка об орфографии**, если AI вернул `fix`: «Похоже, пишется **książce**» и кнопка «Исправить». По кнопке форма заменяется на `fix`. Без нажатия **ничего не меняется**.
- **Перевод (ru)**, редактируемое поле, предзаполнено AI.
- **Начальная форма (base)**, редактируемое поле. Если пользователь ввёл её сам, она приоритетнее, AI только проверяет её (см. `baseCheck`).
- **Пометка о форме (note)**, редактируемое поле, например `rzeka → rzece, C./Msc. l.poj., k→c`.
- **Чекбокс «Добавить»**, по умолчанию включён. Выключен по умолчанию, если `isPolish = false` или `confidence = "low"` (для фото).
- Для фото дополнительно бейдж «неуверенно прочитано», если `confidence = "low"`.

Над списком: «Пропущено повторов: N», если такие формы уже есть в карточках.
Кнопки: **«Сохранить (N)»** и **«Отмена»**.
При сохранении строки без перевода не сохраняются, пользователь видит тост: «Добавлено: X. Без перевода не сохраняю».

## 4. Контракт с AI

Модель: актуальная Claude (`claude-sonnet-5-5` через API, либо capability `sample` в артефакте). Ответ строго JSON, порядок элементов совпадает с порядком на входе. Парсить терпимо: целиком, из блока ```json или от первой `[`/`{` до последней `]`/`}`. При неудаче показать кнопку «Ещё раз», **автоматически не ретраить в цикле**.

### 4.1. Перевод форм (батч)

Вход: массив `{pl, base?}`.

Промпт (рабочая версия из проекта «Pisz po polsku», расширенная начальной формой):

```
Rosyjskojęzyczna uczennica zapisuje polskie słowa i frazy DOKŁADNIE w tej formie, w jakiej je spotkała (często odmienione), żeby zapamiętać pisownię końcówek i wymiany głosek (r → rz, k → c, g → dz, ó → o itd.). Na fiszce zobaczy tłumaczenie rosyjskie i będzie musiała napisać z pamięci właśnie TĘ formę.
Pozycje (forma; w nawiasie kwadratowym forma podstawowa podana przez uczennicę, jeśli jest):
1. rzece
2. poszłam [pójść]
...
Dla każdej pozycji, w tej samej kolejności:
- "ru": tłumaczenie na rosyjski, które oddaje tę konkretną formę (przypadek, liczba, osoba, czas, rodzaj), np. „o morzu” → „о море”, „poszłam” → „(я) пошла”, „rzece” → „реке (дат./предл. п.)”. Jeśli z rosyjskiego tłumaczenia nie da się odgadnąć formy, dodaj w nawiasie krótką wskazówkę po rosyjsku.
- "base": forma podstawowa (mianownik l.poj. / bezokolicznik). Jeśli uczennica podała własną i jest poprawna — zwróć ją bez zmian.
- "baseCheck": "" jeśli forma podstawowa uczennicy jest poprawna albo jej nie podała; w przeciwnym razie krótko po rosyjsku, co nie tak.
- "form": nazwa formy po polsku, skrótowo, np. „C./Msc. l.poj.”, „cz. przeszły, 1 os. l.poj., ż.”.
- "alternation": wymiana głosek między formą podstawową a tą formą, np. „k→c”, „ó→o”, albo "".
- "note": krótko po polsku (max 60 znaków): „rzeka → rzece, C./Msc. l.poj., k→c”. Dla formy podstawowej: rodzaj albo aspekt.
- "fix": jeśli w zapisie jest błąd ortograficzny (np. brak ogonka), podaj poprawny zapis TEJ SAMEJ formy; w przeciwnym razie "".
- "isPolish": false, jeśli to nie jest polskie słowo.
Niczego nie zmieniaj w samej formie i nie sprowadzaj do formy słownikowej.
Odpowiedz tylko tablicą JSON: [{"ru":"","base":"","baseCheck":"","form":"","alternation":"","note":"","fix":"","isPolish":true}]
```

### 4.2. Распознавание фото

Вход: 1–N изображений и режим (`highlighted` или `all`).

```
Na zdjęciu (zdjęciach) są notatki lub strona z podręcznika do nauki polskiego. Uczennica mówi po rosyjsku.
Tryb: {highlighted: "Wypisz TYLKO polskie słowa i frazy wyróżnione: podkreślone, zakreślone, zaznaczone markerem, wypisane na marginesie." | all: "Wypisz wszystkie polskie słowa i frazy, które wyglądają na słownictwo do nauki (pomiń całe zdania z ćwiczeń, numery, nagłówki)."}
Zasady:
- Przepisz każdą pozycję DOKŁADNIE tak, jak jest napisana: ta sama forma (przypadek, osoba, czas) i ten sam zapis, nawet z błędem. Niczego nie poprawiaj i nie sprowadzaj do formy podstawowej.
- Jeśli obok jest rosyjskie tłumaczenie, wpisz je do "ru". Jeśli obok jest forma podstawowa (np. w nawiasie), wpisz ją do "base".
- Rosyjskich słów nie traktuj jako pozycji.
- "confidence": "high" albo "low" (nieczytelne pismo, niepewne litery). Niepewne litery zaznacz w "pl" jako [?].
- Bez powtórzeń.
Odpowiedz tylko tablicą JSON: [{"pl":"","ru":"","base":"","confidence":"high"}]
```

После 4.2 элементы без `ru` или `base` отправить в 4.1.

## 5. Модель данных карточки

```
{
  id,                // стабильный: slug(pl) + hash(pl + ru)
  pl,                // форма ровно как ввёл пользователь (или после «Исправить»)
  ru,                // перевод этой формы
  base,              // начальная форма ("" если совпадает с pl)
  form,              // грамматическая форма
  alternation,       // "k→c" или ""
  note,              // короткая пометка для показа после ответа
  topic,             // колода/тема, по умолчанию "moje"
  source,            // "manual" | "list" | "photo" | "text" (из читалки)
  photoId,           // необязательно
  created,           // ISO
  box, due, right, wrong   // поля интервального повторения (как в проекте)
}
```

Дубликаты определяются по нормализованной `pl`: нижний регистр, обрезанные пробелы, схлопнутые пробелы, без пунктуации. **Разные формы одного слова — это разные карточки** (`rzeka` и `rzece`), в этом весь смысл. Одинаковая форма повторно не добавляется.

## 6. Как карточка работает в повторении

- **Лицевая сторона:** `ru` с подсказкой о форме в скобках, если она есть. Ответ пользователь вводит с клавиатуры. Поле ввода с `autocorrect=off`, `autocapitalize=off`, `spellcheck=false`, `lang="pl"`.
- **Сравнение строгое, с диакритикой.** Если отличаются только ogonki или одна буква в длинном слове, ответ засчитывается как «почти». Показываем побуквенный дифф, ошибку пишем в банк ошибок с типом (ó/u, rz/ż, ch/h, ą/ę, ogonki).
- **После ответа** показываем `base → pl` и `alternation`, например `rzeka → rzece (k→c)`. Так закрепляется чередование.
- Подсказка «начальная форма» доступна как одна из ступеней подсказки, она снижает оценку карточки.

## 7. Ошибки и крайние случаи

| Ситуация | Поведение |
|---|---|
| AI недоступен (нет ключа, оффлайн, не дан доступ) | Экран проверки с пустыми полями перевода для ручного ввода. Текст: «Перевод можно вписать вручную» |
| Невалидный JSON | Сообщение и кнопка «Ещё раз». То, что уже введено, не теряется |
| AI вернул меньше элементов, чем отправили | Недостающим строкам оставить пустой перевод и пометить «нет перевода» |
| Слово не польское (`isPolish=false`) | Строка видна, чекбокс снят, бейдж «не похоже на польское» |
| Пользователь указал неверную начальную форму | Его вариант остаётся в поле, под ним `baseCheck` жёлтым |
| Фото нечитаемое или пустой результат | «Не нашла польских слов на фото. Попробуй режим „Все польские слова“ или сфотографируй ближе» |
| Фото слишком большое или не того типа | Понятное сообщение об ограничении: допустимые типы и размер |
| Все слова уже есть | Тост «Эти слова уже есть в тетради», экран проверки не открывается |

## 8. Критерии приёмки (проверить руками)

1. `rzece` даёт перевод «реке (дат./предл. п.)», base `rzeka`, alternation `k→c`. Сохранённая `pl` равна `rzece`.
2. `o morzu` даёт «о море», base `morze`.
3. `poszłam [pójść]` даёт «(я) пошла», base остаётся `pójść`, `baseCheck` пустой.
4. `poszłam [iść]` даёт заполненный `baseCheck` (видовая пара: pójść / iść). Поле base остаётся `iść`, пока пользователь не поменяет.
5. `ksiazce` показывает подсказку «Похоже, пишется książce». Без нажатия «Исправить» сохраняется `ksiazce`, с нажатием сохраняется `książce`.
6. Строка `morzu, przy rzece, poszłam` превращается в 3 элемента. Строки `załatwić sprawę — уладить дело` и `kot\tкот` не уходят в AI, если начальная форма не нужна.
7. Фото тетради с тремя подчёркнутыми словами в режиме «Только выделенное» даёт ровно эти 3 слова в исходной форме.
8. Повторное добавление существующей формы даёт «Пропущено повторов: 1».
9. В повторении после ответа на `rzece` видно `rzeka → rzece (k→c)`.
